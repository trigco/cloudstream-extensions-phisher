# XFlixBD CloudStream Provider

Native CloudStream plugin module for the public catalogue pages at https://xflixbd.org.

Includes catalogue browsing, category pages, search, title metadata, and delegation of accessible public player embeds to CloudStream's built-in extractor registry.

This provider is marked beta while the live site's markup and player behavior are validated. It does not bypass logins, DRM, CAPTCHA/bot checks, paywalls, or other access controls. Use only content you are authorized to access.

Build follows the CloudStream plugin repository workflow and produces a `.cs3` plugin package:
https://recloudstream.github.io/csdocs/devs/gettingstarted/
